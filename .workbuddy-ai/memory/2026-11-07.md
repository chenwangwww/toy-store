## 后台订单管理功能（只写文档，用户自己抄）

文档：`docs/admin-order-management.md`（7 个文件：4 新建 / 3 修改，1147 行）。
需求：后台加订单管理，支持按用户邮箱筛选 + 编辑订单状态。

**设计要点**：
- 邮箱用 `contains` 模糊匹配（管理员记不住完整地址）；SQLite LIKE 对 ASCII 本身不区分大小写。
- 状态角标用**两份 where**：`scopeWhere`（只含邮箱）给 `groupBy` 统计，`where`（邮箱+状态）给列表。
  否则点某个状态后其他角标全变 0。
- 改状态连带改库存：改成 CANCELLED → stock+N/sales-N；从 CANCELLED 改回 → 反向，且**先整体校验库存够不够**，
  不够返回 409，避免扣成负数。`order.status === 新状态` 时直接返回，不碰库存（否则连点两次会还两次）。
- 行内原生 `<select>` + `confirm`：**取消时必须手动 `select.value = order.status`**，
  因为 value prop 没变 React 不会重置 DOM，下拉框会停在用户刚选的值上。
