# 2026-11-25

## 修复 CI lint 失败（apps/web）

- 报错：`apps/web/src/components/AuthModal.tsx` 中 `useEffect` 里同步 `setState`，触发新版 react-hooks 规则 `react-hooks/set-state-in-effect`（error，导致 CI exit 1）。
- 修复方式：删除该 `useEffect`，改为 `switchMode(mode)` 辅助函数——先重置 password / confirmPassword / code / message / error，再 `dispatch(setAuthModalMode(mode))`；重置密码成功后的 `setTimeout` 也改用它。
- 结论：`pnpm -r lint` 现在 0 error（剩余 6 个 `<img>` 相关 warning，不阻断 CI）；`tsc --noEmit` 通过。
- 备注：本项目用 Next.js 新版 + eslint-config-next 的 core-web-vitals，effect 内同步 setState 属硬错误，状态重置应在事件处理里做。
