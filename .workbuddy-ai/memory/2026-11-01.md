# 2026-11-01

## 后台用户管理：顶部「客户 / 后台管理员」标签栏

- 需求：`/admin/users` 顶部加标签栏，把客户和后台管理员分开看；同时把改动整理成可照抄的文档。
- 实现（4 个文件）：
  - `packages/shared/src/index.ts`：新增 `AdminUserRole = 'customer' | 'admin'`、`AdminUserListResult`（在 `PaginatedResult` 上多加 `counts`）。
  - `apps/api/src/app/api/admin/users/route.ts`：`GET` 新增 `role` 参数（`customer`(默认) | `admin` | `all`），直接映射到 `where.isAdmin`；返回体加 `counts: { customer, admin }`（全量计数，不吃 keyword/status 条件）。
  - `apps/admin/src/services/adminApi.ts`：`getUsers` 支持 `role`，返回类型改 `AdminUserListResult`，删掉不再使用的 `PaginatedResult` import。
  - `apps/admin/src/app/admin/users/page.tsx`：`ROLE_TABS` 数据驱动标签栏（带角标）、`counts` 单独 state（避免切标签闪 0）、切标签 `setPage(1)`、管理员标签页隐藏「订单数」列与「封禁」按钮。
- 关键决策：不新增 `role` 字段，复用已有 `User.isAdmin`，避免同一信息存两份。
- 验证：api / admin 两处 `tsc --noEmit` 通过；eslint 仅剩既有的 `<img>` warning；用 tsx 直查 dev.db 确认 counts(2/1)、role 过滤、keyword 不影响 counts。
- 文档：`docs/admin-user-role-tabs.md`（三个整文件代码块与仓库文件逐字节一致，已脚本校验）。
